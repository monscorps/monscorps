# Play Scope — boost.ai scoping explainer

Self-contained animated explainer (single `index.html`, no build step, no
dependencies beyond Google Fonts). Press **Play scope** and six beats run
themselves; space pauses, arrows step.

Visual grammar borrowed from unformentoo.org — Bricolage Grotesque display,
IBM Plex Mono labels, grain over a flat stage, one idea per beat, motion used
only to show a mechanism — recoloured to boost.ai purple and green.

The case it answers: a pre-signature voice expansion for an existing Nordic
insurance chat customer. Copy is placeholder; structure, icons and motion are
the deliverable.

To host it anywhere: drop `index.html` at the root of a repo and enable
GitHub Pages, or open the file directly.
